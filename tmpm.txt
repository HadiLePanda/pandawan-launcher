fix: fetch remote documents through Rust instead of the HTTP plugin

Installing against the R2 bucket failed with "url not allowed on the configured
scope". The Tauri HTTP plugin requires a capability scope listing every allowed
origin, so pointing the launcher at a new bucket meant adding its hostname to
src-tauri/capabilities/default.json and shipping a build.

reqwest is not scoped that way. This routes catalog, news, and manifest fetches
through a new fetch_remote_text command so the Rust allowlist is the entire
security boundary and cannot drift from the deployed host. Game file downloads
already went through reqwest and were unaffected.

Adds a 30s timeout, an 8 MB cap, and an http/https scheme check to the command.
The frontend now has no plugin-http usage at all, so the remote entries in the
capability file can be dropped when the custom domain is live.
