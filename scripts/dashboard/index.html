Launcher release

        

          The launcher ships through CI, not from here: a tag is pushed, all three platforms build
          and sign, and only then is there something to publish. These actions cover the publish
          half, which takes seconds rather than the ~25 minutes a build takes.

Publish catalog

        

          Uploads public/catalog.json (and the news feed) to
          launcher/catalog.json. New or changed games stay invisible to
          the launcher until this runs.
