Prune builds

              

                Deletes old build directories from the bucket. Untick "Delete for real" to see what
                would go first; pinned versions are never removed.
              

              

                

                  
                  
                  
                


                

                  
                  
                

              

              

            


            

              
Catalog

              

                Uploads catalog.json, which is what the launcher's game list reads. A build that has
                not been catalogued stays invisible to players.
              

              

                
              

              

            


            
            

              
Game metadata

              

                Edit how a published game presents itself: its name, description, genres and
                artwork. The build itself is not touched and no game files are re-uploaded. Load a
                game to fill this in from what is live now, edit what changed, review the diff, then
                publish. Preview only stays on until you turn it off, and unsaved edits are kept if
                you reload.
