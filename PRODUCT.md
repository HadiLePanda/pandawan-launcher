# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- **Primary: players** who download the Pandawan Launcher, browse the company’s game catalog, install and update games, manage their local library, and launch titles.

There is no public publishing audience; game catalog and update content is managed by Pandawan Corp.

## Product Purpose

A straightforward, company-owned desktop launcher for Pandawan Corp games. It lets players browse available titles, install and manage local copies, launch games, and receive game patches and launcher updates with minimal friction.

## Positioning

A simple, self-updating client for a company-controlled catalog — like Blizzard’s Battle.net launcher at indie scale. Games and updates are published only by Pandawan Corp via a remote CDN; the launcher is not a marketplace, store platform, or white-label distribution tool for third parties.

## Operating Context

- **Runtime:** Tauri v2 desktop app with a React + TypeScript UI running in a webview. Packaged for Windows as the primary target; macOS and Linux builds are enabled by Tauri and CI but remain on the product roadmap.
- **Distribution:** Users download and install the launcher binary. The launcher connects to a remote CDN for the catalog, per-game manifests, patch notes, news, and update bundles.
- **Catalog model:** `catalog.json` lists available games; each game’s `manifest.json` (generated by `scripts/generate-manifest.py`) provides version, files, and SHA256 hashes. Games are updated by replacing the manifest and files on the CDN — no launcher rebuild required.
- **Fallbacks:** If the remote catalog is unreachable, the launcher falls back to the embedded `public/catalog.json` and shows a connectivity banner. A `catalog.override.json` in the app data dir is available for dev/QA only.
- **Windowing:** Frameless window with a custom title bar (`TitleBar`) and standard window controls.
- **Persistence:** Settings are saved as JSON in the Tauri app data directory; playtime and last-played are recorded on game exit.
- **Security/release workflow:** Launcher self-updates are signed with minisign. `src-tauri/updater.pub` is committed; the secret key lives in `src-tauri/.secrets/updater.key` and in the `TAURI_SIGNING_PRIVATE_KEY` GitHub Secret. Releases are cut from `main` via `v*.*.*` tags.
- **Development:** `npm run tauri:dev` runs the local Vite frontend and Rust backend. A local example server (`examples/StartExampleServer.bat`) serves catalog/manifest examples for offline UI testing.

## Capabilities and Constraints

**Current capabilities**
- Browse a remote catalog of Pandawan Corp games with icons, banners, descriptions, genres, and screenshots.
- Install, update, launch, uninstall, and verify installed games.
- Hash-based patching and integrity verification (SHA256).
- Resume-capable, parallel downloads with progress reporting.
- Automatic game-update checks and optional OS notifications for available/completed updates.
- Launcher self-update check and install flow.
- Playtime tracking and last-played timestamps.
- Multi-language UI: English, French, German, Spanish.
- Dark / light / system-adaptive themes.
- Configurable install path, download speed limit, max concurrent downloads, and notification toggles.
- System-tray minimize/close behavior.
- “Open logs folder” from Settings → About; logs written as rotating JSON lines in the app log dir.

**Known constraints**
- The in-app **Store** and **Player Profile** are UI placeholders with no backend or purchase/account behavior.
- `notifyFriendActivity` and `notifyNewsEvents` settings exist in the schema but are not wired to behavior.
- Games must be configured and uploaded by Pandawan Corp; there is no end-user or third-party publishing path.
- Updater signing is required for production builds and releases.
- `src/lib/bindings.ts` is currently hand-maintained because the Specta export test cannot run in this environment; it must be regenerated on a Tauri-capable machine before release.

## Brand Commitments

- **Name and identity:** Pandawan Corp, panda mascot.
- **Personality:** Indie · Chill · Premium but Simple · Connected · Positive.
- **Visual system:** Dual-mode brand world defined in `docs/BRAND_GUIDE.md`: “Tech Forest” dark mode and “Parchment & Stone” light mode. Typography uses Geist Sans and JetBrains Mono.

## Product Principles

1. **Player-first operation.** The launcher’s job is to get the player into the game quickly; management actions should be obvious and low-friction.
2. **Trust through transparency.** Show real download/update progress, verification results, clear errors, and accessible logs.
3. **Calm, crafted interface.** Keep the UI neutral and premium; reserve color for purposeful actions and rare errors.
4. **Company-controlled catalog.** The launcher is a client for Pandawan Corp’s published catalog and updates, not an open platform.
5. **Respect user control.** Let players choose install location, bandwidth limits, theme, language, notifications, and tray behavior.
