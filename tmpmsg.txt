docs: define game build naming and derive channel from version

Adds docs/GAME_BUILDS.md as the contract a Unity build script must follow, and
enforces the most error-prone part of it in the publisher.

- Channel is now derived from the semver prerelease (0.4.0-alpha.3 -> alpha,
  1.0.0 -> stable) instead of being a separate parameter that could contradict
  the version string. A contradicting --channel is now an error.
- An unrecognised prerelease such as 0.4.0-alfa.1 fails loudly rather than
  falling back to stable, which would mislabel a test build for every player.
- Documents the split builds/<slug>/<version>/<platform>/ layout, the platform
  keys shared with Tauri's latest.json, the exclusion list, build-report.json,
  and the git tag pattern.
- Builds stay unzipped for publishing: the launcher patches per file, so
  shipping a zip would force a full re-download on every update. The zip is for
  archival only.
